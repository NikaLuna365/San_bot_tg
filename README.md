# Telegram-Бот для Психологического Мониторинга

## 📝 Описание

Этот Telegram-бот предназначен для регулярного отслеживания эмоционального и психологического состояния пользователя. Он проводит ежедневные опросы, формирует ретроспективы за периоды и использует AI (Google Gemini) для анализа ответов и предоставления поддерживающей обратной связи.

## ✨ Основные Функции

*   **Ежедневные Опросы:** Короткие тесты с уникальным набором вопросов для каждого дня недели (6 закрытых вопросов с оценкой 1-7 и 2 открытых вопроса).
*   **AI-Анализ Опросов:** Интерпретация результатов ежедневного теста с использованием Google Gemini, предоставление эмпатичной обратной связи и возможности для дальнейшего диалога.
*   **Мгновенная Ретроспектива:** Анализ динамики состояния пользователя за последнюю 1 или 2 недели на основе пройденных тестов.
*   **AI-Анализ Ретроспектив:** Подробный отчет от AI по итогам ретроспективы, включающий анализ средних показателей, качественных ответов и наводящие вопросы.
*   **Диалог с AI:** Возможность задать уточняющие вопросы или поделиться мыслями после получения анализа опроса или ретроспективы.
*   **Настройка Часового Пояса:** Установка корректного часового пояса пользователя (поддерживаются форматы IANA, например, `Europe/Moscow`, и смещения GMT/UTC, например, `GMT+3`, `UTC-5`) для точной работы напоминаний и расписаний.
*   **Напоминания:**
    *   Настройка ежедневных напоминаний о прохождении теста в удобное для пользователя время.
    *   Настройка запланированной ретроспективы (еженедельной или двухнедельной) на конкретный день недели и время.
*   **Сохранение Данных:** Результаты тестов и ретроспектив сохраняются (в текущей версии - в JSON файлы), настройки напоминаний и часовых поясов - в PostgreSQL. Состояния диалогов сохраняются между перезапусками (через PicklePersistence).

## 💻 Стек Технологий

*   **Python 3.10+**
*   **python-telegram-bot v20+** (включая `JobQueue` для планировщика)
*   **PostgreSQL** (для хранения настроек)
*   **asyncpg** (асинхронный драйвер для PostgreSQL)
*   **Google Gemini API** (`google-generativeai`) (для AI-анализа)
*   **Docker & Docker Compose** (для контейнеризации и развертывания)
*   **aiofiles** (для асинхронной работы с файлами)

## 🚀 Установка и Запуск

### Предварительные требования

*   Установленные **Docker** и **Docker Compose**.

### Шаги

1.  **Клонировать репозиторий:**
    ```bash
    git clone <URL вашего репозитория>
    cd <папка проекта>
    ```

2.  **Создать файл `.env`:**
    Создайте файл с именем `.env` в корневой директории проекта и добавьте в него необходимые переменные окружения. **Никогда не добавляйте этот файл в систему контроля версий (Git)!**

    **.env.example:**
    ```dotenv
    # Токен вашего Telegram-бота (получить у @BotFather)
    TELEGRAM_BOT_TOKEN=<ВАШ_TELEGRAM_BOT_TOKEN>

    # API-ключ для Google Gemini API
    GEMINI_API_KEY=<ВАШ_GEMINI_API_KEY>

    # Строка подключения к базе данных PostgreSQL
    # Формат: postgresql://<user>:<password>@<db_service_name>:<port>/<db_name>
    # db_service_name - имя сервиса БД из docker-compose.yml (обычно 'db')
    # port - порт ВНУТРИ сети Docker (обычно 5432)
    DATABASE_URL=postgresql://username:password@db:5432/dbname

    # (Опционально) Название модели Gemini, если хотите использовать другую
    # GEMINI_MODEL_NAME=gemini-1.5-pro
    ```    *Замените значения в `<...>` на ваши реальные данные. `username`, `password`, `dbname` должны совпадать с переменными `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` в `docker-compose.yml`.*

3.  **Запустить проект:**
    *   **Собрать Docker-образ:**
        ```bash
        docker-compose build
        ```
    *   **Запустить контейнеры (бот и БД) в фоновом режиме:**
        ```bash
        docker-compose up -d
        ```

4.  **Проверить логи (опционально):**
    ```bash
    docker-compose logs -f telegram-bot
    ```
    *(Нажмите `Ctrl+C` для выхода из просмотра логов)*

5.  **Остановка проекта:**
    ```bash
    docker-compose down
    ```

## ⚙️ Конфигурация Docker

*   **`.dockerignore`:** Файл указывает Docker, какие файлы и папки игнорировать при копировании в образ, чтобы уменьшить его размер и избежать попадания ненужных данных (например, `.git`, `.env`, `__pycache__`).
    ```
    __pycache__/
    *.pyc
    *.pyo
    *.pyd
    venv/
    .git/
    .env
    *.log
    data/
    logs/
    persistence/
    *.pickle
    ```
*   **`docker-compose.yml`:**
    *   Определяет два сервиса: `telegram-bot` (сам бот) и `db` (база данных PostgreSQL).
    *   Использует `healthcheck` для сервиса `db`, чтобы бот стартовал только после полной готовности базы данных.
    *   **Volumes:**
        *   `./data:/app/data`: Пробрасывает папку `data` с хоста в контейнер для хранения JSON-файлов.
        *   `./logs:/app/logs`: Пробрасывает папку `logs` для хранения лог-файлов бота.
        *   `./persistence:/app/persistence`: Пробрасывает папку `persistence` для хранения файла состояний `PicklePersistence`.
        *   `db_data:/var/lib/postgresql/data`: Именованный volume для хранения данных PostgreSQL.
    *   **Порты:** Порт `5433` хоста пробрасывается на порт `5432` контейнера `db` для возможного внешнего подключения к БД (например, для отладки).

## 🤖 Использование Бота

*   **`/start`:** Начать общение с ботом, отображает главное меню.
*   **Кнопка "Тест":** Запустить ежедневный опрос.
*   **Кнопка "Ретроспектива":** Запустить мгновенную ретроспективу за 1 или 2 недели.
*   **Кнопка "Напоминание":** Настроить ежедневное напоминание о тесте или запланированную ретроспективу.
*   **Кнопка "Настроить часовой пояс" (или команда `/set_timezone`):** Установить ваш часовой пояс для корректной работы напоминаний. **Важно сделать это перед настройкой напоминаний!** Поддерживаются форматы IANA (`Europe/Moscow`) и GMT/UTC (`GMT+3`, `UTC-6`).
*   **Кнопка "Помощь" (или команда `/help`):** Показать справочную информацию.
*   **Кнопка "Главное меню":** Доступна во время большинства диалогов для отмены текущего действия и возврата в главное меню.
